# AI Gesture Studio

A web application that recognizes hand gestures from video files in real-time using machine learning.

## How to Run

**Option 1: Quick Start (Windows)**
1. Double-click the `start.bat` file.
2. The app will open automatically in your browser.

**Option 2: Using VS Code**
1. Open the project folder in Visual Studio Code.
2. Press `F5` to start the local server and launch the app.

## Main Files
- `Index.html` - The main web page and interface.
- `start.bat` / `start-server.ps1` - Scripts to run the local server.
- `test-gestures.mp4` - A sample video used to test the gesture recognition.

## Tech Stack
- HTML, CSS, JavaScript
- Google MediaPipe (Vision tasks)
